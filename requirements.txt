# pywebview : requis pour l'interface graphique recommandée
# (job_watch/webapp.py), qui affiche toute l'appli — y compris l'aperçu
# des annonces en iframe — dans une fenêtre Edge/Chromium (comme
# NovaVox). Optionnel pour la version Tkinter (job_watch/gui.py), où il
# sert seulement au bouton "Ouvrir en grand".
#
# NovaVox plafonne cette dépendance à <5.3, mais sur ce poste c'est
# l'inverse qui a été constaté : la 5.2 affiche une page blanche même
# pour une simple URL externe, alors que la dernière version (6.x)
# affiche correctement le contenu. Ne pas replafonner sans avoir
# revérifié sur la machine cible.
pywebview

# Optionnelles, seulement pour la version Tkinter (job_watch/gui.py) :
# le panneau d'aperçu intégré y essaie tkinterweb (moteur HTML léger,
# sans JavaScript, et actuellement incompatible avec Tcl/Tk 9) puis se
# rabat sur un simple message si indisponible.
tkinterweb
